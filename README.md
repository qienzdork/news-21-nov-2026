# The World Today — 21 November 2026

A program that draws a newspaper front page summing up the world news of
Saturday 21 November 2026, as a single 1024×1024 image.

Run it with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes `entry.png` into the output directory. The program runs with no
network and is deterministic: every run writes the same bytes.
